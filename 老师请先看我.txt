这是我的《多平台作业通知自动整理与提醒系统》期末项目。

推荐检查方式：

1. 直接打开线上地址：
   https://homework-reminder-wm0m.onrender.com/

2. 如果需要查看本地项目：
   请先安装 Node.js，然后双击 start-mac.command（Mac）或 start-windows.bat（Windows）。
   如果无法双击，请在终端中运行：
   npm install
   npm start

3. 浏览器打开：
   http://localhost:3000
